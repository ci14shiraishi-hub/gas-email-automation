# Gmail問い合わせ自動集計システム (GAS)

## 概要
Gmailに届く特定の定型メール（問い合わせや注文通知など）を定期的に自動検索し、本文から必要な情報を正規表現で抽出してGoogleスプレッドシートに自動転記するシステムです。

## 主な機能とエラーハンドリング
- **自動抽出**: 正規表現 (`match`) を用い、本文から「氏名」「メールアドレス」「問い合わせ内容」を正確に抽出。
- **二重登録防止**: 処理が完了したメールには自動で「既読」フラグを付与し、次回以降の実行対象から除外。
- **エラー処理**: 過去のイレギュラーなメールや抽出対象の項目が空欄の場合、スプレッドシートへの書き込みをスキップする堅牢な設計。
- **完全自動化**: 時間主導型トリガー（10分毎）を設定し、PCを閉じた状態でも24時間サーバーサイドで自律稼働。

## 解決するビジネス課題
- 営業事務や経理担当者の「毎日のメール確認とExcelへのコピペ作業」をゼロにし、ヒューマンエラーを防ぎます。
